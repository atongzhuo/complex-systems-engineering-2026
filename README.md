## 如何更新

1. **网页**：在 GitHub 上直接编辑文件，提交到 `main`，约一分钟后自动发布。
2. **Git**：克隆仓库，修改后推送到 `main`。
3. **AI 工具**：用 AI 助手生成或改写内容，再提交推送。

```bash
git clone https://github.com/atongzhuo/complex-systems-engineering-2026.git
cd complex-systems-engineering-2026
# 修改文件后
git add .
git commit -m "update content"
git push origin main
```
